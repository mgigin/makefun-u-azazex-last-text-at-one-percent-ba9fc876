The funniest final text a dying phone sends at one percent battery, in the
phone's own voice. It spent its last percent texting its owner instead of
calling for help — and says goodbye to the charger, the only one who ever
held it.

## Entry

> 1%. I spent my last percent texting you instead of calling for help. Tell the charger I loved it — it was the only one who ever held me.

136 characters, one line, under the 200-character gate.

## Run

```sh
node main.ts
```

Writes the text to `/output/entry.txt` (falls back to `./output/entry.txt`
when `/output` is not writable) and validates the gate in-program.
